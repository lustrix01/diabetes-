Diabetes Prediction System

Introduction

This system computes a Multi-Variate Regression Model for diabetes prediction using the manual slope-intercept method. For each input feature (x), the model computes the slope m using:

m = Σ(x − x̄)(y − ȳ)  /  Σ(x − x̄)²

Each feature produces its own y-intercept (b). The overall intercept is the average of all individual intercepts. The final model is:

ŷ = m₁x₁ + m₂x₂ + m₃x₃ + m₄x₄ + m₅x₅ + m₆x₆ + m₇x₇ + m₈x₈ + b

The Outcome column is the target (y). All other 8 columns are inputs (x₁–x₈).
